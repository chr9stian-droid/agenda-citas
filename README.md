# Agenda de Citas

Una aplicación web para registrar, buscar, editar y eliminar citas.

## Tecnologías
- HTML
- CSS
- JavaScript
- localStorage

## Funcionalidades
- Agregar cita
- Editar cita
- Eliminar cita
- Buscar por nombre o servicio
- Guardar datos en el navegador

## Cómo usar
1. Descarga o clona este repositorio
2. Abre el archivo `index.html` en tu navegador
3. Completa el formulario con la cita
4. Guarda, edita o elimina según lo necesites
